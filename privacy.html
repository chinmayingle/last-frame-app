Privacy policy

The Last Frame channel tool (Google OAuth app “story”) · effective 11 November 2026

Who uses it

Only the owner of the YouTube channel The Last Frame, to manage that one channel. The tool has no other users.

What it accesses

When the owner signs in with Google, the tool receives OAuth tokens that allow it to upload videos to the channel, manage the channel's videos and playlists, read and reply to comments, and read channel analytics.

How the data is used

Only to publish and manage the owner's own videos and to review how the channel is doing. Channel data retrieved through the API (such as video titles, statistics and comments) may be processed by the owner's AI assistant (Anthropic's Claude), which helps run the channel on the owner's instructions.

Storage and sharing

  • OAuth tokens are stored only on the owner's own computer and are never sent to any server run by this tool.
  • No data is sold, shared with advertisers, or used for any purpose other than managing this channel.
  • This website sets no cookies and runs no analytics.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. Revoked tokens stop working immediately, and the owner can delete the stored copy from their computer.

Contact

Open an issue at github.com/chinmayingle/last-frame-app.
